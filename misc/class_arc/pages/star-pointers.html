Pointers are amazing!

I'm probably the only person you would ever hear say that, but it's true. Not just because I want it to be true.

 

Pointers, like their name suggest, point to other things. How?

Well everything in a program has a location at any given time. For instance a variable x could be at an address 0x7FFF1321. Why this specific address? (No particular reason).

The computer uses that address to find what x is at any given time. One thing that sticks out from the address is that it is a number. This isn't a coincidence, that same number is the number the computer uses to find x (this will be important later).

In essence a pointer is just that number. [int* ptrx = &x ; // (0x7FFF1321)]

Now why do we care? Well everything is memory.

 

Your variable? Memory

Your function? Memory

Your class? Memory

 

Because pointers let you interact with memory, pointers let you interact with Anything.

// Valid C/C++ code
int x = 300 ; // 0x012C
int* p = &x ;
char two[2] = {0, 0}; // 0x00 0x00
*((int*)two) = *p; // two = { 0x01, 0x2C }

Cool. Hell yes.
