The GNU GCC/G++ compiler is really 4 different programs all masquerading as one. Each program corresponds to the 4 stages in compiling source code.

  1. Preprocessor
  2. Compiler
  3. Assembler
  4. Linker

I have briefly mentioned a few of these stages in previous pages, but I will be expanding on them further here.

Preprocessor

The preprocessor is the first stage of the compilation process. Its general task is to scan through the file, replace any definitions it finds, include various other files, and handle macros.

That is pretty much all it does as it just sets up your code to be finally compiled.

Compiler

The compilation is the second stage of the compilation process. This is where the Compiler scans though all of the code looking for symbols so that it can translate all your code into computer readable assembly. Depending on your flags/settings the compiler can also optimize your code or include various debugging tools into the executable.

You would be surprised at various complicated processes and the many different fields of academia this covers (Notably linguistics). Compilers are really cool pieces of software, but this all we need to know about them.

Assembler

The assembler is the third stage of the compilation process. If I am being honest, the complexity drastically falls off around this point as Assembly is a one to one translation into binary. This stage takes the assembly generated by the compiler and turns it into object code (basically a big chunk of binary data, with links to other things).

Linker

The Linker is the forth and final stage of the compilation process. All it does is it takes the object code created by the Assembler and links all the object files into one executable. Its rare you should ever have to do this, but this stage is vital if you were compiling for a system with different executable requirements.

For instance the SNES has 48 megabits of program rom, the linker for the SNES has to create a 48 megabit rom file in a very specific way, otherwise the SNES will not run.

I should note that we will NEVER do this in this class, I just thought I should bring it up since I though it was interesting.
